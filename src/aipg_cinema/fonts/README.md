# Caption Font

Noto Sans, unmodified variable font from the official Google Fonts repository:

- Source: `google/fonts`, revision `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.
- Upstream path: `ofl/notosans/NotoSans[wdth,wght].ttf`.
- Font SHA-256: `bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.
- License: SIL Open Font License 1.1, included as `OFL.txt`.
- Copyright: The Noto Project Authors. This asset is not relicensed under MIT.

`coverage.json` is mechanically generated from the font's best Unicode cmap
using FontTools. It records supported code-point ranges, not a claim that this
font covers all scripts or emoji. The caption renderer rejects unsupported
glyphs rather than silently exporting replacement boxes. No font or network
download is needed when running an installed application.

# Display Fonts

Unmodified OFL fonts from `google/fonts` revision
`45e3d5269e4a17d823f6d84470bc084dc5ae46f6`, renamed only to avoid brackets in
package paths. Each license is included beside the font; none is relicensed
under MIT. `display.json` records each file's SHA-256 and FontTools cmap ranges;
renderers fall back to Noto Sans for any unsupported character.

Playfair Display carries the Reserved Font Name "Playfair Display"; these files
are unmodified, so the name is retained.
